# Curses

Fabric 1.21.11 mod that adds six joke/cursed enchantments:

- Butterfingers
- Reverse Knockback
- Pacifist's Rage
- Loud Steps
- Gravity Tax
- Unstable Mending

The enchantments are defined in data-driven JSON under `/src/main/resources/data/curses/enchantment`, while their cursed runtime behavior is implemented with Fabric hooks and mixins in the Java sources.
